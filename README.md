# 할 일 목록

브라우저에서 바로 실행되는 간단한 할 일 목록 웹페이지입니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

## 기능

- 할 일 추가 / 완료 체크 / 삭제
- 더블클릭으로 수정 (Enter 저장, Esc 취소)
- 전체 / 진행 중 / 완료 필터
- 완료 항목 일괄 삭제
- 브라우저(localStorage)에 자동 저장
- 다크 모드 자동 지원

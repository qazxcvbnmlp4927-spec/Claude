# 부캉이의 북항시 탈출

북항시 수로에 들어온 흑상어 부캉이를 넓은 바다까지 데려다주는 액션 게임입니다. 2026년 9월 부산 북항 친수공원 수로에 나타난 흑상어 '부캉이' 이야기에서 영감을 받아 만든 비공식 팬 게임이에요. 그림과 소리는 모두 코드로 직접 그리고 합성했습니다.

## 실행 방법

`index.html` 파일 하나를 브라우저로 열면 됩니다. 휴대폰과 컴퓨터 모두 됩니다.

## 하는 법

| 조작 | 휴대폰 | 컴퓨터 |
| --- | --- | --- |
| 움직이기 | 화면을 끌기 | 방향키 · WASD (마우스로 끌어도 됨) |
| 돌진 | 오른쪽 아래 돌진 버튼 | 스페이스 · Shift |
| 그물 찢기 | 화면 마구 탭 | 스페이스 연타 |
| 일시정지 | 오른쪽 위 버튼 | Esc · P |

- 돌진은 기운 한 칸(전체의 1/3)을 쓰고 잠깐 무적이 됩니다. 그물은 돌진으로 뚫을 수 없어요.
- 고등어를 먹으면 점수와 기운이 오릅니다. 연달아 먹으면 점수가 커지고, 황금 고등어는 하트를 하나 채워 줍니다.
- 장애물에 아슬아슬하게 스치면 보너스 점수, 수로 가장자리 가까이 헤엄치면 구경꾼이 인증샷을 찍어 줍니다.
- 하트를 모두 잃으면 그 구간 처음부터 다시 할 수 있습니다.
- 난이도: 쉬움(하트 5개, 조금 느리고 그물 틈이 넓음), 보통(하트 3개), 어려움(하드코어: 하트 1개, 20% 빠름, 그물 틈이 좁고 장애물이 더 많고 촘촘함, 그물 연타 12번, 지면 처음부터). 지옥(밤바다라 부캉이 주변만 보임, 하트 1개, 55% 빠름, 몇 초마다 옆으로 미는 해류, 돌진해도 무적 아님, 그물 틈이 더 좁고 흔들림, 닻 경고가 짧음, 황금 고등어 없음, 그물 연타 18번). 최고 점수는 난이도마다 따로 기록됩니다.

## 구간

1. **친수공원 수로**: 구경꾼이 가득한 좁은 수로. 떠다니는 쓰레기, 카약, 오리배, 다리 기둥.
2. **북항 부두**: 대어 놓은 큰 배 때문에 길이 좁아지고, 예인선이 가로지르고, 닻이 떨어집니다.
3. **방파제 그물길**: 그물 사이 틈(움직이는 틈도 있음)을 찾아 지나가고, 떠다니는 폐그물을 피합니다.
4. **넓은 바다**: 기름띠, 해파리, 어선을 지나면 탈출 성공.

장애물 배치는 판마다 새로 만들어집니다.

## 고치는 법

`index.html` 은 `src/` 의 파일을 합쳐서 만든 결과물입니다. `src/` 를 고친 뒤 다시 합칩니다.

```bash
node tools/bundle.mjs
```

- `src/core.js`: 화면 크기, 소리 합성, 저장
- `src/level.js`: 구간 설정과 장애물 배치
- `src/ents.js`: 장애물 움직임과 충돌
- `src/game.js`: 게임 규칙 (점수, 하트, 돌진, 그물)
- `src/draw-world.js`, `src/draw-actors.js`: 그리기
- `src/ui.js`: 메뉴, 화면 위 정보, 조작 연결
- `src/style.css`, `src/body.html`: 화면 구성

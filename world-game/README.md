# 땅따먹기 월드

세계 지도 위에서 땅을 넓혀 가는 실시간 전략 게임입니다. 로블록스의 RoWorld, 그리고 그 바탕이 된 오픈소스 게임 OpenFront와 같은 방식으로 놀 수 있게 새로 만들었습니다. 코드나 그림은 가져오지 않았습니다.

## 실행 방법

`index.html` 파일 하나를 브라우저로 열면 됩니다. 따로 설치할 것은 없습니다.

## 하는 법

1. 지도를 눌러 시작할 곳을 고릅니다. 12초가 지나거나 "바로 시작"을 누르면 게임이 시작됩니다.
2. 빈 땅이나 다른 나라 땅을 누르면 공격합니다. 아래 막대로 보낼 병력 비율을 정합니다.
3. 바다 건너 땅을 누르면 배가 병력을 싣고 갑니다. 배는 한 번에 3척까지 보낼 수 있습니다.
4. 내 땅을 누르면 건물을 짓습니다.
5. 다른 나라를 길게 누르면(컴퓨터에서는 오른쪽 클릭) 동맹 요청, 병력·골드 지원, 핵 공격 메뉴가 나옵니다.
6. 세계 땅의 80%를 차지하면 이깁니다.

병력은 시간이 지나면 다시 찹니다. 땅이 넓고 도시가 많을수록 최대 병력이 늘어납니다. 상대 병력이 촘촘할수록, 그리고 산과 고지대일수록 땅을 빼앗기 어렵습니다.

| 건물 | 하는 일 |
| --- | --- |
| 도시 | 최대 병력 +125K |
| 항구 | 바닷가에만 지을 수 있습니다. 다른 나라 항구와 무역선을 주고받아 양쪽 모두 골드를 법니다. |
| 방어 기지 | 주변 땅을 빼앗기 어렵게 만듭니다. 적에게 빼앗기면 무너집니다. |
| 공장 | 근처 도시·항구·공장과 기찻길로 이어져 기차가 오갈 때마다 골드를 법니다. |
| 미사일 기지 | 원자폭탄, 수소폭탄, MIRV를 쏠 수 있습니다. |
| SAM 발사대 | 근처로 날아오는 핵을 확률로 떨어뜨립니다. |

같은 건물을 더 지을수록 값이 오릅니다. 핵이 떨어진 땅은 주인이 사라지고, 한동안 낙진 때문에 다시 차지하기 어렵습니다.

동맹은 5분 동안 이어지며, 끝나기 전에 연장을 요청할 수 있습니다. 동맹을 먼저 깨면 60초 동안 배신자가 되어 방어가 약해집니다.

난이도에 따라 컴퓨터 나라가 처음 몇 분 동안 나를 공격하지 않습니다 (쉬움 4분, 보통 2분, 어려움 30초). 어려움에서는 내가 1등이 되면 컴퓨터 나라들이 나를 집중해서 노리고, 동맹을 배신하기도 합니다.

## 고치는 법

`index.html` 은 `src/` 의 파일을 합쳐서 만든 결과물입니다. 고칠 때는 `src/` 를 고친 뒤 다시 합칩니다.

```bash
npm install          # 지도 데이터를 다시 만들 때만 필요
npm run build:map    # src/map-data.js 다시 만들기 (Natural Earth 육지 데이터)
npm run build        # src/ → index.html
```

- `src/game.js`: 게임 규칙, 컴퓨터 나라, 화면 그리기, 조작
- `src/style.css`, `src/body.html`: 화면 구성
- `src/map-data.js`: 512×239 칸 세계 지도 (자동 생성)
- `tools/build-map.mjs`: 지도 만들기. 산맥과 고원 위치는 이 파일에 직접 적어 두었습니다.

지도 데이터: [Natural Earth](https://www.naturalearthdata.com/) (퍼블릭 도메인), [world-atlas](https://github.com/topojson/world-atlas) 패키지로 받음.
